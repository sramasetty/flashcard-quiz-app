# Flashcard Quiz App

A modern, responsive React application for testing vocabulary.

## Description

This app allows users to test their knowledge using flashcards. Users are presented with a word and four possible translations. Correct answers increase the score, while incorrect answers reset it to zero. The app features a clean UI, instant visual feedback, and a final results screen.

## 🚀 Features

- **Interactive Flashcards:** Test your knowledge with dynamically generated questions.
- **Instant Feedback:** Visual cues (green/red buttons and badges) immediately show if an answer is correct or incorrect.
- **Score Tracking:** Score increases with correct answers and resets to zero on a mistake.
- **Responsive Design:** Fully playable on mobile, tablet, and desktop screens.
- **Results Screen:** A dedicated game-over screen displaying your final score and a "Play Again" option.

## 🛠️ Tech Stack

- **React:** A JavaScript library for building user interfaces.
- **Vite:** A blazing-fast build tool and development server.
- **Tailwind CSS:** A utility-first CSS framework for rapid UI development.

## 📦 Installation & Setup

To run this project locally on your machine, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### Steps

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Navigate to the project directory:

   ```bash
   git clone <your-repository-url>
   ```

3. Install the necessary dependencies:

   ```bash
   cd flashcard-quiz-app
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser and visit the local URL provided in your terminal (usually http://localhost:5173).
